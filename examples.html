🎯 GitHub Profile Counter

Dynamic view counters with beautiful badges powered by Cloudflare Workers

⚠️ Note: Replace localhost:8788 with your deployed Worker URL (e.g., your-worker.workers.dev) when using in production.

🔢 JSON API Examples

Get Profile Count (Auto-increment)

GET http://localhost:8788/count/octocat
{ "count": 42, "profile": "octocat" }

Get Website Count (Auto-increment)

GET http://localhost:8788/website/example.com
{ "count": 1337, "domain": "example.com" }

Get Profile Stats (Read-only, No Increment)

GET http://localhost:8788/stats/octocat
{ "count": 42, "profile": "octocat", "incremented": false }

Get Website Stats (Read-only, No Increment)

GET http://localhost:8788/stats/website/example.com
{ "count": 1337, "domain": "example.com", "incremented": false }

📝 Usage in GitHub README

Markdown Example

# Hi there 👋 ![Profile Views](https://your-worker.workers.dev/badge/yourusername?style=flat-square&color=blue) ## About Me I'm a developer who loves to code! ## Stats ![Website Views](https://your-worker.workers.dev/badge/mywebsite.com?style=for-the-badge&color=green)

⚡ Rate Limits

Endpoint Limit Reason
Badge 300/hour Higher limit for README embeds
Count/Website 30/hour Conservative for API calls
Stats 1000/hour Read-only, no increment
